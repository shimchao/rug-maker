# Rug Maker

내가 고른 이미지로 바탕화면 위에 러그를 깔아요. 마우스로 구기고, 접고, 다시 펼 수 있어요.

- 맥(Apple 실리콘, M1 이후 칩)과 윈도우(64비트)에서 써요. 윈도우 버전은 아직 윈도우 PC에서 시험해 보지 못한 베타예요.
- 이미지는 내 컴퓨터 안에서만 처리하고 어디로도 보내지 않아요. 외부로 통신하는 코드가 없어요.

## 내려받기
이 저장소의 **Releases** 페이지에서 내 컴퓨터에 맞는 파일을 받으세요.
- 맥: `RugMaker-…-macOS-arm64.zip`
- 윈도우: `RugMaker-…-Windows-x64.zip`

## 설치와 첫 실행 (맥)
1. 받은 zip을 더블클릭해서 압축을 풀어요. `Rug Maker` 앱이 나와요.
2. 앱을 **응용 프로그램** 폴더로 옮겨요.
3. 앱을 더블클릭해요. "개발자를 확인할 수 없다"는 경고가 뜨면 닫아요.
4. 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 「Rug Maker가 차단되었습니다」 옆의 **「그래도 열기」**를 눌러요. 비밀번호나 Touch ID를 입력하고 다시 「열기」를 눌러요.
5. 위 방법이 안 되거나 "손상되었습니다"라고 나오면, 터미널에서 아래 한 줄을 실행한 뒤 다시 열어요. 믿을 수 있는 앱에만 쓰는 명령이에요.
   ```
   xattr -cr "/Applications/Rug Maker.app"
   ```

경고는 처음 한 번만 나와요. 애플 개발자 서명·공증을 받지 않은 앱이라서 생기는 거예요.

## 설치와 첫 실행 (윈도우, 베타)
1. 받은 zip을 오른쪽 클릭 → 「모두 압축 풀기」를 해요.
2. 나온 폴더 안의 `Rug Maker.exe`를 더블클릭해요.
3. 「Windows의 PC 보호」 화면이 뜨면 **「추가 정보」 → 「실행」**을 눌러요. 서명을 받지 않은 앱이라서 생기는 경고예요.
4. 화면 오른쪽 아래 알림 영역(`^` 안쪽)에 아이콘이 생겨요. 아이콘이나 러그를 오른쪽 클릭하면 메뉴가 열려요.

윈도우에서는 러그가 바탕화면 아이콘 위, 다른 프로그램 창 아래에 놓이도록 만들었는데, 윈도우 PC에서 직접 확인하지는 못했어요. 러그가 안 보이거나 동작이 이상하면 Issues에 남겨 주세요.

## 쓰는 법
- 앱을 켜면 바탕화면에 **고양이 러그**가 깔려요. 맥은 화면 오른쪽 위 **메뉴바**, 윈도우는 오른쪽 아래 **알림 영역**에 아이콘이 생겨요.
- 그 아이콘이나 러그를 오른쪽 클릭하면 메뉴가 열려요. **「이미지 바꾸기…」**로 이미지를 고르거나, 브라우저·사진 앱에서 복사해 둔 이미지는 **「복사한 이미지로 만들기」**로 바로 러그로 만들 수 있어요. png, jpg, jpeg, webp, gif, bmp를 쓸 수 있고 40MB 이하여야 해요.
- 메뉴에서 「크기」(원래 크기 포함), 「무게」(가볍게·보통·묵직하게), 「러그 효과」(없음·아주 약하게·약하게·보통·강하게: 털올이 뭉친 푹신한 직물 질감), 「펼치기」, 「처음 상태로」를 쓸 수 있어요. 모니터가 여러 대면 「화면 선택」이 나타나요.
- 배경이 단색인 이미지는 「배경 지우기」, 그 밖에는 「동그랗게」 「둥근 네모」 「그대로」 중에서 모양을 골라요. 배경이 복잡한 사진은 자동으로 사진 전체를 둥근 네모 러그로 만들어요.

| 조작 | 동작 |
|---|---|
| 왼쪽 드래그 | 구기고 접기 |
| 오른쪽 드래그 (또는 Shift) | 옮기기 |
| 휠 | 크기 바꾸기 |
| 더블클릭 | 펴기 |
| `Cmd+Option+Shift+R` (윈도우 `Ctrl+Alt+Shift+R`) | 숨기기·보이기 |

**러그가 안 보이면:** 러그는 바탕화면 아이콘 바로 위, 일반 창 아래에 놓여요. 다른 창이 덮고 있으면 안 보여요. 창을 모두 최소화하거나 `F11`, 트랙패드 네 손가락 벌리기로 바탕화면을 드러내세요.

끌 때는 아이콘 → 「종료」를 눌러요. 「로그인할 때 자동 시작」은 기본으로 꺼져 있어요.

## 지우기
앱을 지우고(맥은 휴지통, 윈도우는 폴더 삭제), 설정과 이미지 사본이 든 폴더도 지우세요. 맥은 `~/Library/Application Support/Rug Maker`, 윈도우는 `%APPDATA%\Rug Maker`예요.

## 직접 빌드하기
Node.js가 필요해요.
```
npm install
npm start          # 바로 실행
npm run pack:mac   # 맥 앱으로 패키징 (dist/ 에 생겨요)
npm run pack:win   # 윈도우 앱으로 패키징 (맥에서도 만들 수 있어요)
```
